# Искусство рядом

Статический сайт школы рисунка Любови Волковой.

## Локальный запуск

Требуется Node.js 20 или новее.

```bash
npm start
```

По умолчанию сайт откроется на `http://localhost:3000`. Для другого порта:

```bash
PORT=8080 npm start
```

## Деплой на Railway

1. Загрузите папку в GitHub-репозиторий.
2. В Railway выберите **New Project → Deploy from GitHub repo**.
3. Выберите репозиторий. Railway прочитает `railway.json`, соберёт проект через Railpack и запустит `npm start`.
4. В настройках сервиса откройте **Networking → Generate Domain**.

Дополнительные переменные окружения не требуются. Railway автоматически передаёт приложению переменную `PORT`. Проверка готовности доступна по пути `/health`.
